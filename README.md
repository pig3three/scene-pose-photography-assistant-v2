# Scene Pose Photography Assistant V2

场景美姿摄影助手 V2：结合一张已授权的模特参考照片、一张实际拍摄场景照片，以及可选的相机和镜头信息，设计 8 个或 16 个可现场执行的美姿，并生成 `POSE BOARD` 和 `SCENE MAP`。

## 主要功能

- 根据模特可见的脸部、发型、服装、鞋履和身体比例设计动作
- 分析场景的可用站位、光线、纵深、背景、机位和安全区域
- 根据相机画幅、镜头焦距、最大光圈和对焦能力调整拍摄方案
- 为每个姿势提供站位、身体朝向、手腿动作、视线和环境互动
- 提供拍摄距离、光圈、快门下限、对焦模式和现场口令
- 支持自然、俏皮、克制或混合动作风格
- 支持 8 个或 16 个姿势，并避免重复相同的手部与腿部组合
- 生成姿势参考板和带编号的场景机位图

## 如何安装

在 Codex 中从 GitHub 安装：

```text
请安装 https://github.com/pig3three/scene-pose-photography-assistant-v2
```

安装后建议重新打开一个 Codex 任务，或让 Codex 重新加载 Skills。

## 如何调用

上传两张图片，并在提示词中明确图片角色：

1. 图片 1：已获得使用授权的模特参考照片
2. 图片 2：实际拍摄场景照片

然后使用 Skill 名称调用：

```text
用 $scene-pose-photography-assistant-v2 分析这两张照片，并设计 8 个适合现场拍摄的美姿。
```

也可以用自然语言调用：

```text
请使用场景美姿摄影助手 V2，结合模特照片和场景照片设计一组美姿，并生成姿势板和场景站位图。
```

## 指定手部和腿部动作模板

需要更丰富的姿势时，可以直接指定动作覆盖范围。Skill 会把手部、腿部和身体重心分别设计，并避免重复完全相同的组合。

```text
【动作要求】
动作气质：混合，整体自然松弛，加入少量俏皮感

8 个姿势至少包含：
- 1 个单手比 V
- 1 个双手比心
- 1 个张开手掌
- 1 个整理头发
- 1 个双手背后

腿部动作至少包含：
- 前后错步
- 双腿左右分开
- 轻微交叉腿
- 单腿屈膝
- 脚跟抬起
- 行走中间态

不要重复相同的手部和腿部组合。
动作必须符合模特气质、服装、鞋履、场地安全和镜头能力。
```

可以按需要替换或补充以下动作：

- 手部：自然摆臂、张掌挥手、单手或双手比 V、指心、双手比心、整理头发、整理袖口、双手背后、双手低位相握
- 腿部：前后错步、宽站、轻微交叉、侧步、屈膝、抬脚跟、侧点脚尖、行走中间态、半转身过渡

```text
先锁定 16 个文字姿势，再生成：
- POSE BOARD A：P01–P04
- POSE BOARD B：P05–P08
- POSE BOARD C：P09–P12
- POSE BOARD D：P13–P16
- SCENE MAP：标注 P01–P16、摄影师机位、拍摄方向和光线方向
```

## 无器材信息时的模板

相机和镜头不是必填项。如果暂时没有确定器材，可以要求 Skill 使用焦段类别给出建议，而不虚构具体型号。

```text
我还没有确定相机和镜头。
请分别说明广角、标准焦段和中焦人像镜头在这个场景中的适用姿势，
并指出哪一种更适合当前空间。不要假设我拥有某个具体镜头。
```

## 模特参考照片建议

为了得到更可靠的全身美姿和示意图，建议模特参考照片具备：

- 已经获得本人授权
- 正面或略侧面的清晰脸部
- 尽量完整显示发型、上衣、下装、鞋履和配饰
- 避免严重遮挡、过度滤镜或只露出脸部

如果下装、鞋履或完整身体比例不可见，Skill 会把它们标记为“未锁定”，而不是把猜测当成真实信息。生成示意图前，可以由用户明确允许一种中性服装补全方案。

## POSE BOARD 与 SCENE MAP

8 个姿势默认生成：

- `POSE BOARD A`：P01–P04，2×2 四宫格
- `POSE BOARD B`：P05–P08，2×2 四宫格
- `SCENE MAP`：人物站位、摄影师机位、拍摄方向、光线方向及避让区域

为了保持一致性，所有姿势板应使用同一位模特、同一套服装和同一场景结构。示意图重点是站位、手势、腿型和承重关系，不以精确复刻面部细节为唯一目标。

## 使用注意事项

- 只使用用户上传或明确授权的真人参考照片
- 不要求 Skill 识别模特身份，也不要推断敏感个人信息
- 提供器材建议时，镜头焦距必须是实际物理焦距，最大光圈是上限而非每张都必须使用的光圈
- 拍摄距离、曝光参数和景深建议均为现场起始值，需要根据实际光线和空间确认
- 不要要求模特站在车流、临水边缘、松动结构或禁止进入区域
- 动作必须适应实际服装、鞋履、年龄和行动能力
- AI 姿势示意图可能出现手指或场景文字偏差，现场执行以文字姿势和安全判断为准
